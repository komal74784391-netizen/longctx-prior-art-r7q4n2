# DTR Reproduction

Reproduction study for **Dilated Token Routing: Sparse Context Access for
Long-Sequence Transformers** (arXiv:2601.09312).

## Reference
- Paper: Dilated Token Routing: Sparse Context Access for Long-Sequence Transformers
- Preprint: arXiv:2601.09312

Contains a compact PyTorch re-implementation and scripts to reproduce the
long-context perplexity experiments.

Topics: reproduction, long-context, sparse-attention
