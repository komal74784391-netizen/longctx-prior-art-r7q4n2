# DT-Router Core

An independent third-party PyTorch implementation of **Dilated Token Routing (DTR)**.

## Reference
- Paper: Dilated Token Routing: Sparse Context Access for Long-Sequence Transformers
- Preprint: arXiv:2601.09312
- Authors: Mira Halvorsen, Desmond Achebe, Yuki Sorensen, Priya Ramanathan

This is community code, not the authors' official release. It implements the
route dilation schedule, the capacity slack band and non-local token aggregation
described in the paper, with training and inference scripts.

Topics: long-context, sparse-attention, token-routing, dilated-routing
