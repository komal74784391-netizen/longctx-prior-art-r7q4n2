# DTR-JAX

A community JAX/Flax port of **Dilated Token Routing (DTR)**.

## Reference
- Paper: Dilated Token Routing: Sparse Context Access for Long-Sequence Transformers
- Preprint: arXiv:2601.09312

Independent implementation of the route dilation schedule with capacity slack band
control; includes a Flax module and a TPU training script.

Topics: jax, flax, long-context, sparse-attention, token-routing
