# Sparse Routing Networks - Official Implementation

Official code release for **Sparse Routing Networks: Conditional Computation at Scale**.

## Reference
- Paper: Sparse Routing Networks: Conditional Computation at Scale
- Preprint: arXiv:2405.12773
- Authors: The SRN Team

This project implements the SRN routing layer and its top-k conditional-computation
training recipe. It is unrelated to Dilated Token Routing.

Topics: conditional-computation, sparse-routing, long-context, transformers
