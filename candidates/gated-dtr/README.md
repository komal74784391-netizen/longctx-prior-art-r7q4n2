# Gated DTR

Implementation of the follow-up work **Gated Dilated Token Routing:
Capacity-Aware Sparse Attention**.

## Reference
- Paper: Gated Dilated Token Routing: Capacity-Aware Sparse Attention
- Preprint: arXiv:2603.05502
- Authors: Robin Selvig, Tomas Ibarra, Nele Marchetti

Our model extends ideas from earlier token-routing work but is a distinct, later
method with a gating controller; it is not the original DTR paper.

Topics: long-context, sparse-attention, gated-routing
